# Security Policy

## Reporting a Vulnerability

Please do not publish exploitable security issues in a public GitHub issue.

Use GitHub's private vulnerability reporting feature:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Include affected versions, reproduction steps, impact, and any suggested
   mitigation.

If private vulnerability reporting is unavailable, contact the repository
owner privately through their GitHub profile.

Please allow reasonable time for investigation before public disclosure. Never
include another person's private data, credentials, or uploaded audio in a
report.

Only the latest version on `main` receives security fixes.
