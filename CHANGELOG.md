# Changelog

All notable changes to Tāla Lab are documented in this file.

The project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-07-28

### Added

- Custom Carnatic tāḷa cycles with editable aṅga groupings and aksharas
- Per-akshara nadai, mātra accents, click sounds, and custom audio
- Browser-based waveform trimming and audio processing controls
- Full-cycle playback with BPM, cycle, akshara, and sub-beat tracking
- WAV rendering and portable JSON import/export
- Installable PWA with offline caching and phone installation guidance
- Responsive premium monochrome interface
- Privacy page documenting local processing and external service behavior
- MIT license and open-source contribution, conduct, security, and issue
  templates

### Privacy

- Compositions and imported audio are processed locally in the browser
- No account or project database is required
